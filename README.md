# Item Assist Reborn

Подсказчик предметов для магазина Deadlock (Panorama UI-мод). Продолжение заброшенного мода
**Item Assistant** (версия 1.1.1, данные под клиент 6635). Оригинальный рантайм и идея принадлежат
автору Item Assistant; здесь обновление под текущие версии игры и новая статистика.

## Что изменено относительно оригинала

- **Точка входа `hud_health` пересобирается из текущей игры** (`pipeline/make_layout.py`), а не
  хранится устаревшей копией. Старый мод подсовывал HP-бар версии 6635, без полосок брони Rat King
  и `shield_bar_2`.
- **Статистика собирается заново с [deadlock-api](https://deadlock-api.com)** (`pipeline/collect.py`
  + `pipeline/build.py`):
  - винрейт с поправкой на нетворс (`adjusted_win_rate` из `item-flow-stats`) вместо «что покупают
    победители»;
  - учимся у сильных игроков: оценки по лестнице рангов «все → Phantom+ → Ascendant+», где у
    про-игроков мало матчей, оценка подтягивается к более широкой выборке;
  - отдельные оценки по фазам матча (0–9, 9–20, 20–30, 30+ мин);
  - «следующий предмет» по тому, что уже куплено (переходы из `item-flow-stats`);
  - тайминги: до какой минуты предмет окупается (сравнение с предметами того же тира, купленными
    в ту же минуту);
  - матчапы против каждого героя врага с поправкой на сам матчап.

## Настройки в моде (⚙)

- **Мой ранг** — Авто (по значку ранга в матче) или вручную: 1-3 (Initiate–Alchemist),
  4-6 (Arcanist–Emissary), 7-8 (Archon–Oracle), 9+ (Phantom и выше). Для каждого диапазона свои
  таблицы предметов: на разных рангах предметы реально работают по-разному (~2 п.п.,
  `research/rank_consistency.py`), и таблицы чужого ранга в симуляции теряли до трети пользы.
- **Автоочередь** — наши 6 предметов становятся очередью быстрой покупки игры.
- **Метки в магазине** — номера на карточках предметов.
- **Прокачка умений** — ▲ над умением, которое качать следующим.

Если ранг в режиме «Авто» не читается, панель явно показывает предупреждение и используемую
таблицу: выберите свой диапазон через ⚙. Поиск значка продолжается в течение матча.

Панель и автоочередь выбирают тир накопления по экономике: нетворсу из HUD, если он читается,
или сумме доступных душ и стоимости текущих предметов. Поглощённые компоненты не считаются
дважды. Для накопления поднимается только одна цель, близкая по оценке к лучшему совету;
сам по себе высокий тир не даёт бонуса. Дешёвый предмет с сильной контрой или синергией
может прервать накопление. Без данных текущей фазы предмету нужна контекстная поддержка.
Источник оценки и сумма записываются в `[IAR]`.

Покупки врагов — свидетельство из ленты, а не подтверждённый текущий инвентарь. Их влияние
постепенно уменьшается: до 5 минут при известном владельце, до 2 минут без него. Улучшение
заменяет компоненты только у того же известного героя. Продажи противника не видны моду,
поэтому бессрочно считать купленный предмет текущим владением нельзя.

Сортировка всегда Blend (частота покупки + 20 × оценка винрейта): чистая частота в симуляции
оказывалась хуже случайного, когда сообщество недооценивает сильные предметы.

Интерфейс Deadlock не умеет сохранять настройки (`$.persistentStorage` в игре нет), поэтому
переключатели в игре действуют до её закрытия. Постоянные значения задаются в
[settings.json](settings.json) и вшиваются в мод при `pack.py`.

Обоснование — [docs/research_state_and_robustness.md](docs/research_state_and_robustness.md).

## Структура

```
pipeline/   сбор и обработка данных, генерация layout, упаковка VPK
mod_src/    исходники мода (JS, CSS, layout) + prebuilt/ уже скомпилированные ассеты
data/       сгенерированные данные (recommender_data.js), отчёты; cache/ не в git
```

## Сборка

```bash
cd pipeline
python collect.py          # свежий срез, кэшируется в data/cache
python collect.py --resume # продолжить тот же срез после прерывания
python build.py            # -> data/recommender_data.js + data/build_report.txt
python make_layout.py      # -> mod_src/panorama/layout/hud_health.xml из текущей игры
python pack.py --pak 30    # компиляция + dist/pak30_dir.vpk (--install кладёт в addons)
```

Нужны: Python 3.11+, установленная Deadlock,
[Source2Viewer CLI](https://github.com/ValveResourceFormat/ValveResourceFormat/releases) для
декомпиляции layout, CS2 с бесплатным DLC **Counter-Strike 2 Workshop Tools** (его
`resourcecompiler.exe` компилирует Panorama-ресурсы, которые понимает Deadlock).

На Linux `pack.py` сам находит Steam-библиотеки и запускает компилятор через Wine:

```bash
python pipeline/pack.py --install
```

Нужны `wine` в PATH и Windows-файлы CS2: в Steam включите для CS2 совместимость Proton
и установите Workshop Tools. При необходимости задайте `--cs2`, `--addons`, `--wine`
или `--wine-prefix`. По умолчанию отдельный Wine-префикс хранится в `build/wine`.
Скрипт удаляет старый скомпилированный ассет перед запуском, чтобы не упаковать его после ошибки.

Коллектор фиксирует `since` и `until` в `data/run.json`, а также сохраняет версию ассетов.
`--resume` использует те же границы и кэш; обычный новый запуск создаёт свежий срез.
`meta.snapshot_until` в данных обозначает верхнюю границу статистики, а `client_version` —
версию установленного клиента. Таблицы контрпредметов и текстовые подсказки пока наследуются
из прежних данных; обновлённая дата статистики не делает их автоматически новыми.

## Установка

Готовый `pakNN_dir.vpk` кладётся в `Deadlock/game/citadel/addons/`. Номер выбирайте свободный, чтобы
не перезаписать другой мод.

Если папка `addons` ещё не подключена, в `Deadlock/game/citadel/gameinfo.gi` добавьте
в блок `FileSystem → SearchPaths` перед строкой `Game citadel`:

```text
Game    citadel/addons
Mod     citadel
Write   citadel
```

Перед изменением сохраните копию `gameinfo.gi`. Полностью перезапустите игру после установки.
Обновление игры или проверка файлов Steam может сбросить эти строки.
